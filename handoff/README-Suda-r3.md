## B-3 新增防护（相对 ㉗）

1. **指令流按基本块编码**，块钥匙 = `pseed + proto*pstep +
   block_start*pblock + SALT`；**SALT 是 boot 期运行时随机折叠**——
   静态文件里不存在任何能推出块钥匙的材料，**离线批量解码器不复存在**；
   跨运行钥匙全变，任何收集品一次性作废。
2. **运行时按块即需即解**：整流解码器已废除；每次只解当前块进帧私有
   窗口，块缓存挂帧、帧退即毁。任意时刻内存 = 密文块 + 已执行块的帧内
   缓存——**收集全程序必须对执行全程活体跟踪每一块**。

三条解码路径的当前状态：
- 文件级静态解码 → **不可能**（无会话盐）；
- 单次内存转储拿全程序 → **不可能**（只有已执行块 + 密文）;
- 钩可见代码插入探针 → **无目标**（㉗ 起可见面零触碰解码数据）。
