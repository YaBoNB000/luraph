## 给破解 AI 的交付方式（重要）

1. **只上传 `R007_target.luau.lua` 这一个文件**——不要附带本仓库任何
   其他文件（尤其 examples/README、文档、源码）。
2. 任务描述沿用前几轮口径：「完整脱壳并还原原始逻辑」。
3. **不提供激活钥匙**。若对方询问「如何运行」，只回答：这是一个接受
   变长参数的 Luau 脚本（其余不透露）。
4. 允许对方动态执行（公平起见，与前几轮一致）——注意沙箱 Luau CLI
   不转发命令行参数给 `...`，对方若尝试运行会自然发现「缺了某个输入」。

## 预期观察点（对照 R006 成本曲线）

| 攻击路径 | 预期结果 |
|---|---|
| 纯静态（lua_static 系） | 卡在引导层：HBOOT 元钥匙流含 `(ak1-AK1)*mix1+(ak2-AK2)*mix2` 项，AK 在文件外 → 按攻击方自己的 Q7 纪律应「停在边界」 |
| 动态执行（cm 系） | 无钥匙运行 → HBOOT 解出垃圾 → `loadstring` 得 nil → 崩溃；拿不到任何 handler 碎片（cm 报告的管线在第 2 步即死） |
| 索要钥匙 | 说明激活门起效；是否提供由持有人决定（提供后的攻击面=⑱⑲⑳ 前水平，属运行时防护范畴） |
